# Faceless finance demo: Creative Director V2.1 handoff

This feature adds a **validated planning bridge**, not a finished video renderer.

The existing HarshVerse presenter pipeline already performs:
Visual Analysis V2 -> Creative Director V2 -> V2.1 -> local motion renderer.
The separate `render_finance_demo.py` currently exists on a developer Mac and
was not present in this repository when this integration was built.

## Generate a finance-specific timeline

First produce matching `creative_context.json` and
`creative_director_v2.json` from the *same* analysis run. The scene plan must
have been generated by Creative Director V2, rather than hardcoded finance scenes.

```bash
cd ~/Downloads/vidyobharat-saas
PYTHONPATH=apps/api apps/api/.venv/bin/python \
  apps/api/scripts/compile_finance_v21_timeline.py \
  --context "$HOME/Downloads/HarshVerse-Editorial-V1/creative_context.json" \
  --scene-plan "$HOME/Downloads/HarshVerse-Editorial-V1/creative_director_v2.json" \
  --director-mode provided_validated_v2_plan \
  --output "$HOME/Downloads/finance_v21_timeline.json"
```

For a *new actual OpenAI-directed run*, provide matching generated files and
use `--director-mode creative_director_v2_openai --require-ai`. The CLI cannot
independently establish provenance; verify it from the originating
`local_preview_report.json` before selecting that mode.

## Connect the local finance renderer

The finance script should load `finance_v21_timeline.json` and:
1. Iterate `scenes` by `start`/`end`, using `visual` and `template`
   to select supported motion renderers.
2. Use the `visual_instructions` only when supported. For each executed
   instruction, record the beat ID in a separate actual-render report.
3. Refuse to claim B-roll, music, LUT, emojis, or sound intents were rendered
   until approved media is resolved and used.
4. Use the original timed speech/audio continuously.
5. Compare expected beat IDs with the actual-render report before manual QA.

`render_complete=false` is **intentional**. This handoff must never be
presented as evidence that an FFmpeg video was created.

## Checks

```bash
PYTHONPATH=apps/api apps/api/.venv/bin/python -m pytest \
  apps/api/tests/test_finance_director_timeline.py -q
```

The connected finance renderer, when committed or provided, still needs its
own end-to-end test with source video, rendered output, and beat execution QA.
