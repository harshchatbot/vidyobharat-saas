# Creative Director V2.1 — Motion and composition contract

**Scope:** implemented a deterministic, review-only composition compiler from
validated V2 narrative scenes. This is NOT a renderer, and does not modify
the existing editor/Celery/export pipeline.

## Inputs
1. Existing compact `CreativeContext` from Video Analysis V2.
2. Validated `ScenePlanV2`, typically generated by `run_creative_director_v2.py`.
3. Optional public, approved asset inventory snapshot from
   `GET /api/editor/visual-assets`. The initial LUT/emoji/music seed
   records are drafts and do NOT appear in that public inventory.

## Output contract
- `version: "2.1"`
- `duration_seconds`, `aspect_ratio`, `needs_review: true`,
  `ready_to_render: false`
- `base_video_uninterrupted: true`, `source_audio_uninterrupted: true`
- `captions_owned_by: "deterministic_editor"`
- `beats`: typed, time-bounded source, continuity, typography, zoom,
  phrase-synchronized motion-graphic, B-roll intent, SFX intent, and optional
  approved LUT, emoji and music intents.
- Keyframes: relative times, easing, opacity, zoom and vertical motion.
- Layout: full canvas, face-safe graphics, or validated upper caption lane.
- Asset IDs are **only** emitted when present in a supplied published/verified
  inventory and matching relevant tags. Drafts, arbitrary URLs or unknown files
  never resolve to a usable asset.
- B-roll/SFX without approved assets remain unresolved suggestions and preserve
  the original footage and voice. Background music suggestions use low gain,
  but actual voice ducking / normalization must be implemented in the renderer.

**Continuity:** scene timecodes are derived from known phrases and every
source pause/gap is explicitly preserved as original video/audio, including
time before the first phrase and after the last phrase.

**Long scenes:** graphic overlays are divided into phrase-synced visual
microbeats, rather than leaving a single static data-flow diagram on screen
for seven seconds.

## Limits and next implementation

The composition is **not professional finished video yet**. The proposed
motion template names do not automatically imply built and tested animations;
scene geometry is a strict semantic lane, not verified pixel positions for
every video frame; existing sparse face detection may require review. Likewise
none of the imported media can be used until an actual checked, licensed asset
file has been published.

Next: render the `data_flow` template with keyframe/beat parity in browser
preview and ffmpeg/Celery export; add collision checks, audio ducking, QC
screenshots, license provenance and post-render QA. Roll out behind a feature
flag. Keep V1.1/V2 as stable experimental baselines.
